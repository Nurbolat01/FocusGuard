# FocusGuard 🛡️

**FocusGuard** is a Windows desktop utility designed to boost productivity and reduce digital distractions by limiting access to games. The application automatically detects installed Steam games and enforces system-level launch restrictions, requiring administrator rights to change settings.

---

## ✨ Features (v0.1)

- **🎮 Steam Library Auto-Detection:** Scans your local environment and generates a list of installed Steam games.
- **🚫 Game Access Control:** Selectively restrict or limit access to specific games from your list.
- **🔒 Admin Protection:** Requires Administrator privileges to enable or disable restrictions, preventing quick bypasses.
- **🖥️ Desktop Interface:** Clean GUI built for simple, straightforward setup.

---

## 🚀 Future Roadmap

FocusGuard is actively expanding beyond basic game management. Upcoming releases will feature:
